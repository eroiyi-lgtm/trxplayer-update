# TrxPlayer – Update-Dateien

Nur die fertigen Update-Dateien der TrxPlayer-App (kein Quellcode, keine Inhalte).
Die App liest `version.json` über GitHub Pages: https://eroiyi-lgtm.github.io/trxplayer-update/version.json

- `trxplayer-<ver>.apk` – Android TV / Fire TV / Handy
- `lg-<ver>.html` – Oberfläche für LG webOS (Selbst-Update)
- `tizen-<ver>.html` – Oberfläche für Samsung Tizen (Selbst-Update)
